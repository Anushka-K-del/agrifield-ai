# Agrifield.ai (AgriShield AI) 🌿

AI-Driven Smart Agriculture & Crop Health Ecosystem.

## Features

- **3D Crop Ecosystem**: Interactive WebGL 3D terrain canvas and sensor node map.
- **AI Diagnostics**: Early crop disease detection and edge IoT sensing.
- **Vernacular LLM Voice Intelligence**: Real-time voice intelligence for farmers.

## Live Deployment

- Hosted on **Vercel**: High-performance global CDN deployment.
- Framework: **Vite + React 19 + TailwindCSS + Three.js**.
